## Current status

**Stage: Arts Quarter vertical slice**, not a complete 70-master production library.

- 10 approved JSON master specifications; 6 bound to real gameplay IDs and 4 decorative.
- Two reproducible glTF 2.0 GLBs per master (LOD0/LOD1) via `npm run assets:build`.
- GLTFLoader caching, city chunk manager, distance-sensitive LOD manager, named collider / anchors, graceful legacy mesh fallback.
- Native Blender `.blend` master files are generated by `blender_factory.py` when executed inside Blender; **none are claimed to be produced by the Node fallback**.

## Editable Blender master generation

Requires Blender 4.x executable installed and available on PATH. Blender MCP was **not available** in the runtime used for this slice; the `bpy` generator is ready for a Blender MCP wrapper or headless Blender job:

```bash
blender -b --factory-startup --python tools/asset-factory/blender_factory.py -- \
  --spec assets/specs/arts-quarter.slice.json \
  --masters assets/source/arts-quarter \
  --out public/assets/mt-city/slice-2 \
  --count 10
```

This is the **canonical Blender path** and generates:
- `assets/source/arts-quarter/<id>.blend`: editable scene, materials, named empties
- `public/assets/mt-city/slice-2/<id>.lod0.glb`
- `public/assets/mt-city/slice-2/<id>.lod1.glb`
- `public/assets/mt-city/slice-2/blender-export-report.json`

Keep Blender-produced .blend files in version control (Git LFS recommended) or upload them to a reproducible asset store. Don't run `npm run assets:build` *after* exporting Blender GLBs into the same folder: the web fallback deliberately regenerates and overwrites its own binaries. Once Blender masters pass visual/browser QA, change the build mode to copy native Blender output from a separate versioned directory, then bump `assets/specs/arts-quarter.slice.json` version and the asset registry. This prevents accidentally mislabeling fallback meshes as Blender outputs.

## JSON master specification

`assets/specs/arts-quarter.slice.json` is the source of truth. Add a new master with unique `id`, `class`, `palette`, `width`, `depth`, `height`, `floors`, `seed` and `roof`. For interactive assets set `gameplayId` to an existing `cityLots[].id`; decorative models set `decorative:true` and add placement under `decorativePlacements`.

Keep **game entity ID independent of mesh name, Blender object IDs and GLB filename**. Do not add decorative IDs to the save schema. Decorative objects have no click handlers.

Y-up meters, horizontal X/Z, front +Z, ground y=0. Required anchors:
`ANCHOR_Entrance`, `ANCHOR_Sign`, `ANCHOR_Roof`, `COLLIDER_Footprint`.

## Validation gates

| Gate | Current support |
|---|---|
| Asset/placement/gameplay IDs unique | automated test |
| GLB header, declared byte length, valid JSON and mesh | automated test |
| Polygon budgets LOD0 ≤ 1,800, LOD1 ≤ 360 | generated report + automated test |
| Named anchors, dimensions, declared units/orientation | automated test |
| Deterministic content SHA-256 | byte-for-byte verification |
| Raycast building selection | original building-ID callback preserved in GLB interaction adapter; **browser QA pending** |
| Cache, fallback and chunk unload | implemented; memory behavior **browser QA pending** |
| Camera, onboarding, campaigns, save/load | existing automated tests; manual 3D regression **pending** |
| Visual consistency front/side/top | **Blender QA pending** |
| FPS, draw calls and GPU memory | **not measured yet**; do not infer from test success |

Target ≥30 FPS on typical integrated graphics is a future benchmark target, **not a measured result**. Geometry/disk benchmarks are available in `qa-report.json` after build.

## Scaling plan

Only after 10 masters pass browser/Blender QA: expand to **70 canonical masters**, then approximately **268 deterministic variants** across creative/client/rival/office/residential/retail/facilities/urban prop categories. Implement material-merged variants, shared meshes, visible-range chunk streaming and optional KTX2 textures after measuring browser resource usage. Avoid loading all variants into the game at once.
